# Literature matrix

Starter matrix for the [review protocol](LITERATURE_REVIEW_PROTOCOL.md). Entries identify relevant primary sources; gaps are research implications and details marked **verify** require full-text extraction. This is not a completed screening log or a claim that all five themes have been exhaustively reviewed.

| Study and theme | Dataset / setting | Metrics or evaluation | Methodological baseline / contribution | Gap or relevance to this project |
|---|---|---|---|---|
| [Chawla et al. (2002), SMOTE](https://doi.org/10.1613/jair.953) — imbalance | Multiple imbalanced classification datasets; exact datasets and prevalence: verify. | ROC-space comparison; exact reported measures: verify. | Synthetic minority oversampling, with undersampling comparisons. | Not a temporal fraud deployment study; compare SMOTE with class weighting inside training folds only. |
| [Dal Pozzolo et al. (2015), probability calibration](https://doi.org/10.1109/SSCI.2015.7376526) — imbalance | Unbalanced classification and fraud context; exact datasets: verify. | Probability calibration and classification evaluation; exact metrics: verify. | Undersampling and posterior-probability correction. | Sampling changes prevalence; verify calibration on naturally distributed validation data. |
| [Dal Pozzolo et al., realistic fraud modelling](https://dalpozz.github.io/static/pdf/TNNLS_2017.pdf) — temporal leakage | Real-world credit-card transaction setting with delayed feedback. | Fraud detection under delayed supervision; exact metrics and split: verify. | Models delayed labels and feedback separately in a changing environment. | ULB has no explicit delayed-label process; chronological splitting alone does not simulate label availability. |
| [Ma et al. (2026)](https://doi.org/10.3390/app16136734) — metaheuristics | ULB, 284,807 transactions and 492 frauds; stratified test of 85,443 transactions and 148 frauds. | Authors report GA-XGBoost PR-AUC 0.798 and ROC-AUC 0.967. | RF feature selection and GA search performed within training data or folds; original-prevalence test. | Stratified evaluation is not future-period validation; assess equal budgets before attributing gains to GA. |
| [Lundberg and Lee (2017), SHAP](https://proceedings.neurips.cc/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html) — XAI | General model explanation; datasets: verify. | Explanation properties and comparisons; exact metrics: verify. | Unified additive feature-attribution framework. | Attribution describes model behaviour, not causality; PCA variables limit domain interpretation. |
| [Lundberg et al. (2020), TreeSHAP](https://doi.org/10.1038/s42256-019-0138-9) — XAI | Tree-model applications including health data; exact datasets: verify. | Explanation computation and model understanding; exact measurements: verify. | Efficient tree-ensemble Shapley explanations. | Measure explanation latency and background sensitivity for this project's models. |
| [Dal Pozzolo et al. (2014), practitioner perspective](https://doi.org/10.1016/j.eswa.2014.02.026) — serving | Practitioner credit-card fraud setting; data details: verify. | Operational fraud-detection challenges; latency measurements: verify. | Real-world fraud system constraints and evaluation context. | Does not establish this prototype's end-to-end throughput; separately benchmark inference and explanations under representative load. |
| [Conservative plausibility-filtered SMOTE (2026)](https://doi.org/10.3389/frai.2026.1871972) — imbalance and validation | Deduplicated ULB and IEEE-CIS; ULB has 473 frauds in 283,726 transactions. | Stratified 60/20/20 train/calibration/test; inspect the paper for exact metric definitions and results. | Training-only imputation, scaling, and augmentation. | Avoids cross-partition fitting but the stratified split does not demonstrate later-period generalization. |
| [Breskuvienė and Dzemyda (2024)](https://doi.org/10.1186/s40537-024-01059-5) — temporal validation | Fraud datasets in the study; verify each dataset and prevalence before extracting scores. | Earliest 80% training and later 20% test; see paper for dataset-specific metrics. | Time-ordered evaluation and feature selection for imbalance. | Chronological evaluation addresses a different question from random splitting; results remain dependent on dataset and protocol. |

## Extraction fields for new studies

Record authors/year/DOI, review theme, dataset and size, fraud prevalence, temporal coverage and split, label delay, preprocessing and resampling, models and baselines, tuning budget and seed, metric definitions and results, serving workload and latency, limitations, and relevance. Add the search source and screening decision to the review log. Do not infer an unreported value.
